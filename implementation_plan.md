# План реализации: Mimicry - Академия Языка Тела

Интерактивный тренажёр-игра для изучения языка тела, распознавания микромимики, детекции лжи и применения этих навыков в социальных сценариях.

## Требуется подтверждение от пользователя

> [!NOTE]
> Приложение будет разработано как современное одностраничное веб-приложение (SPA) с использованием **HTML5, Vanilla CSS и современного JavaScript (ES6)**.
> Для создания премиального визуального стиля мы используем **темную стеклянную тему (glassmorphism)** с глубокими фиолетовыми, бирюзовыми, янтарными (для предупреждений/лжи) и изумрудными (для правды) акцентами.
> Также мы добавим звуковые эффекты обратной связи с использованием Web Audio API (без внешних аудиофайлов) и плавные анимации интерфейса.
> Весь интерфейс, база знаний, тесты и сценарии диалогов будут полностью на **русском языке**.

## Компоненты и модули

### 1. Интерактивный атлас (Энциклопедия жестов)
- Разделение по зонам: Глаза и лицо, Руки и жесты, Корпус и осанка, Ноги и положение тела.
- Карточки жестов с описанием психологического значения, контекстом и практическими советами.
- Поиск и фильтрация жестов.

### 2. Викторина и Тренажёр микромимики
- Тесты с выбором ответов по интерпретации поз и мимики в различных ситуациях.
- **Режим микромимики**: выражение лица «вспыхивает» на экране на короткое время (например, 300 мс), после чего пользователю предлагается угадать эмоцию (тренировка быстрого считывания).
- Подробные объяснения к каждому ответу.

### 3. Интерактивный симулятор диалогов (Переговоры и детекция лжи)
- Сюжетные сценарии: *«Собеседование»*, *«Сложные переговоры»*, *«Разоблачение лжеца»*.
- Интерактивный аватар собеседника, у которого меняются позы и выражения лица.
- Диалог содержит вербальные реплики и невербальные сигналы собеседника (описываются текстом и визуальными подсказками).
- Пользователь должен правильно расшифровать жесты оппонента и выбрать верный ответ, чтобы повысить уровень доверия или раскрыть ложь.

### 4. Панель прогресса и геймификация
- Система опыта (XP) и уровней (от «Новичка» до «Живого детектора лжи»).
- Награды и достижения (ачивки): «Чтец лиц», «Гроза лжецов», «Мастер дипломатии».
- Локальное сохранение прогресса в `localStorage`.

## Структура проекта

Мы создадим проект в рабочей директории:

```
c:/Projects/body and antigravity/
├── index.html            # Главная точка входа SPA
├── styles/
│   ├── main.css          # Глобальные стили, темы, glassmorphism и шрифты
│   └── components.css    # Стили для атласа, тестов, симулятора и дашборда
└── js/
    ├── app.js            # Главный контроллер, роутер SPA
    ├── data.js           # База знаний жестов, вопросов викторины и сценариев диалога
    ├── components/
    │   ├── atlas.js      # Компонент Атласа жестов
    │   ├── quiz.js       # Компонент викторины и тренажёра микромимики
    │   ├── simulator.js  # Компонент симулятора диалогов
    │   └── dashboard.js  # Панель прогресса и профиль пользователя
    └── audio.js          # Синтезатор звуков на Web Audio API для UI
```

## План тестирования и верификации

### Ручное тестирование
1. Запуск через локальный веб-сервер и проверка адаптивности (десктопная и мобильная версии).
2. Прохождение полного цикла обучения: изучение жеста -> прохождение викторины -> игра в симулятор.
3. Проверка работы режима микромимики (тайминги скрытия подсказок).
4. Проверка сохранения прогресса и достижений при перезагрузке страницы.
